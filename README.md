# IELTS Writing Practice Tool

A modern, **offline**, AI-powered desktop application for practicing **IELTS Academic Task 1**, **Task 2**, and **Tolimo** writing.

![Task 1 Mode](https://i.imgur.com/3qxaWYF.png)
![Task 2 Mode](https://i.imgur.com/2clIYGH.png)

## ✨ Features

- Side-by-side view for Task 1 (diagram + writing visible at the same time)
- Zoom in/out on diagrams for better detail
- Real-time AI paragraph quality feedback (excellent → good → average → weak)
- Accurate word count with target indicators
- Built-in timer with proofreading alerts
- Scrollable writing area
- Right-click copy/paste (disabled when time ends)
- Random unused Task 2 topics
- Comprehensive Help section
- Fully offline after first launch
